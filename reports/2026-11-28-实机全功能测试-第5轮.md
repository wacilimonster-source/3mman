## 2. 修掉的真 bug：错误提示把 okhttp 英文原样弹给用户

`ApiException.handleException` 里 `HttpException` 分支直接 `ex.message = httpException.getMessage()`，
用户看到的是「HTTP 404 Not Found」。已改为按状态码映射中文：

| 状态码 | 文案 |
|---|---|
| 400 | 请求无效（400） |
| 401 | 登录状态已失效，请重新登录（401） |
| 403 | 访问被拒绝（403） |
| 404 | 内容不存在或链接已失效（404） |
| 405 / 408 | 请求方式不被支持（405） / 请求超时（408） |
| 500 / 502 / 503 / 504 | 服务器内部错误 / 网关错误 / 服务暂不可用 / 网关超时 |
| 其他 | 网络请求失败（HTTP xxx） |

新增 `ApiExceptionHttpMessageTest`（3 项，反射校验映射）。单元测试 **87 项全绿**，lint 0 error。
