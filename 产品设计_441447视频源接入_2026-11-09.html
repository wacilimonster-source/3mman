2. 站点观察与设计依据

评估页面：https://www.441447.xyz/list/video（2026-11-09）。页面标题为「最新视频 · 18yiren.tv」，主导航包含视频、小说、图库、社区等；本次只以视频列表为接入范围。

观察项可确认信息产品含义
来源品牌用户提供域名为 441447.xyz，页面标题品牌显示 18yiren.tv。应用内主显示名建议用「441447」，副标题/来源说明显示「18yiren.tv」；上线前确认品牌与域名关系。
列表结构站点有视频列表、分类导航和视频卡片；列表由 Next.js 前端异步加载。应用分类从站点实时读取，不能把当前分类名称写死在 APK。
列表参数前端脚本读取 contentType=video、page、pageSize、sort、可选 categoryId；默认页大小 20，已看到 latest 与 hot 排序值。首版提供「最新 / 热门」；总数分页优先用接口返回值计算，列表使用 20 条一页。
详情与播放前端脚本读取内容详情，并向 /api/front/videos/{id}/play-url 发送清晰度和线路参数。每次播放时重新解析临时地址；具体清晰度、响应结构、请求头和媒体类型仍需开发验证。
访问条件未带页面会话直接请求分类/列表 API 返回 403；页面脚本先获取 /api/front/client-session。不能把接口当作匿名直连；先验证合法会话流程、频率限制与应用网络栈兼容性。不得绕过站点的登录、年龄验证或安全限制。
资料边界：本稿只核对了公开列表页 HTML 与页面脚本，没有提交年龄验证、登录、播放请求或下载请求。因此分类字段、播放响应、线路/清晰度选项和直链有效期都标记为待技术验证。

3. 目标与范围

目标

  • 用户能从视频页切换到 441447。
  • 能浏览来源分类，查看最新/热门视频并翻页。
  • 点击列表项后尽量进入现有原生播放页。
  • 收藏、来源标记和播放历史能与现有内容区分。

MVP 不做

  • 不接入小说、图库、社区、AI、上传、评论和账户体系。
  • 不将 441447 内容混入主站分类或推荐流。
  • 不在播放 URL 尚未验证时开放下载。
  • 不绕过站点登录、年龄验证、验证码、反滥用或版权限制。

推荐默认

  • 首次进入仍默认主站，避免改变老用户入口。
  • 用户手动选择来源后，记住其上次来源及分类。
  • 来源切换保留两侧各自的分类、排序、滚动位置。

核心用户路径

视频›来源：441447›全部 / 站点分类›最新 / 热门›选择视频›原生播放

6. 页面与交互规格

界面/动作规则空态与错误态
来源切换顶部品牌栏右侧使用紧凑下拉框，显示当前来源。初始默认主站，手动切换后保存选择。各来源使用独立列表缓存。如果 441447 未配置或服务暂不可用，来源仍可选中并展示来源级重试提示。
分类加载拉取视频类别；首项固定「全部」。类别横向滚动；分类 ID 与显示名分开保存。类别请求失败时保留「全部」入口并显示轻量重试，不阻塞全部视频列表。
441447 专属排序「最新 / 热门」工具行仅随 441447 来源展示，默认最新。分类或排序改变时 page 重置为 1、旧请求取消、列表滚到顶部。切回主站后由主站分类导航提供浏览入口。排序加载失败时显示可重试错误提示。
下拉刷新重新请求当前来源、分类、排序的第 1 页；保留分类与排序。刷新失败时保留旧数据并显示「刷新失败，点击重试」。
加载更多按 page/pageSize 增量请求；按稳定内容 ID 去重；没有更多时停止请求。列表为空时显示「暂无视频」；网络错误显示重试按钮，不伪装为末页。
视频卡片封面、标题、时长（有值才显示）、播放量/日期（有值才显示）、来源 badge。标题最多两行。封面缺失使用统一占位；缺字段不影响打开详情。
播放点击即进入共享播放页。进入前请求最新播放地址；播放页保留标题、来源和源站打开入口。地址过期重新解析一次；线路失败可重试或切换接口返回的可用线路；无原生地址时提供源站网页兜底。
收藏复用应用本地收藏与卡片动作；收藏键必须含 sourceId，避免与主站或 91porny 的 ID 碰撞。收藏详情字段缺失时仍允许按 sourceId + contentId 收藏。
下载MVP 默认不显示下载动作。确认得到稳定直链、请求头、Range/HLS 支持和来源授权后再启用。未支持时不显示失效入口；如后续启用，下载失败要明确标出来源错误和可重试状态。
搜索二期在 441447 列表增加站内搜索入口，查询范围限定为当前来源；现有底部「搜索」页保持 91porny 行为。无结果时展示站点无结果态及更换关键词提示。

7. 数据与播放设计

已观察到的站点请求形态

用途请求形态产品/客户端处理
会话启动GET /api/front/client-session先在技术 Spike 中核实必要请求头、cookie、响应校验及可用期限；仅实现站点允许的正常客户端流程。
视频分类GET /api/front/categories?contentType=video缓存短时类别数据；显示名直接使用站点返回，未知字段忽略。
视频列表GET /api/front/contents?contentType=video&page={n}&pageSize=20&sort={latest|hot}&categoryId={id}响应按 items/total 归一化；请求页码与页大小由客户端分页状态管理。
站内搜索（二期）GET /api/front/search?keyword={q}&contentType=video&categoryId={id}&sort={sort}&page={n}&pageSize=20搜索状态与列表状态分离；不混入现有 91porny 搜索结果。
内容详情GET /api/front/contents/{id}?includeChapterContent=false仅取播放所需字段；不请求小说章节或其他内容类型。
播放地址POST /api/front/videos/{id}/play-url，请求体含 resolution、line（前端默认值为 sd/normal）。每次开始播放/用户点重试时请求；不持久化临时 URL。真实字段、可用清晰度、线路和媒体格式需以成功响应为准。

应用侧数据归一化建议

  • 新增独立 source ID：441447；列表项持久化来源为 sourceName=441447，view key 使用 441447/{contentId}，不可仅用站点数字 ID。
  • 新增独立 API/Parser/Repository 边界。不要复用或扩展 PornyServiceApi 的 91porny 端点，也不要在主站分类解析器里加入 441447 分支。
  • 应用列表模型只承载共用展示字段：稳定 ID、标题、封面 URL、时长、播放量、发布日期、来源、作者（若有）、播放上下文。保留原始 JSON 字段供诊断，不把未知字段映射为主站专有语义。
  • 播放解析结果包括媒体 URL、媒体类型、必要请求头、有效期及接口返回的线路/清晰度集合；ExoPlayer 支持的 HLS/MP4 走原生播放器，其他类型显示源站兜底。
  • 类别缓存、列表缓存、播放地址缓存各自隔离；来源切换不清空另一个来源的分页状态。日志避免输出完整临时播放 URL、cookie 或敏感会话值。

8. 异常处理、内容与接入风险

场景用户可见处理处理原则
403 / 会话无效「来源暂时无法访问，请稍后重试」；提供重试和源站打开入口。不循环重试、不绕过年龄验证/验证码/登录和反滥用策略。403 作为配置/权限问题记录。
429 / 限流提示稍后重试，保留现有列表。遵循 Retry-After（如有）；页面滚动不预取多页、不并发刷接口。
5xx / 网络断开错误页或列表内重试；老数据仍可浏览。最多做有限退避重试；取消页面已离开的请求。
播放地址过期提示重新连接，后台刷新地址一次；仍失败时展示线路或源站页面选项。不把一次性的 CDN URL 写入收藏/历史数据库。
原生播放器不兼容显示「此条目暂不支持原生播放」，提供源站网页兜底。不可静默进入黑屏；记录媒体类型和失败阶段，不记敏感 URL。
来源关闭/域名变更来源入口展示可恢复错误态，主站视频功能不受影响。来源配置独立、可远程禁用；不要把 441447 域名写入主站 API 常量。
上线阻断项：若该站点要求绕过验证码、年龄验证、付费墙或其他访问限制才能抓取列表/播放，则停止原生接入，改为提供清晰的源站访问入口；不设计绕过机制。
18+ 内容提示：沿用应用现有 18+ 身份标识与用户内容偏好；来源名称、卡片和错误文案保持中性，不新增成人内容的显式描述。默认关闭自动播放与跨源连播。

MVP 验收标准

  • 首次进入视频页打开主站，来源切换与品牌、下载入口共用 48dp 顶栏。
  • 441447 分类来自接口；分类请求失败不影响「全部」列表的重试入口。
  • 「最新 / 热门」工具行仅在 441447 来源下显示，切回主站时连同整行占位一起收起。
  • 441447 最新/热门切换、分类切换、刷新、加载更多均使用该源参数，分页无重复卡片。
  • 列表字段缺失、封面无效、列表为空和 API 失败都有明确 UI，不导致崩溃或无限加载。
  • 可播放条目一键进入原生播放；返回后回到原来源、分类、排序和原滚动位置。
  • 播放失败会刷新地址一次并给出源站兜底；主站视频仍按原流程播放。
  • 收藏 key 带 441447 source ID，和现有来源不会冲突；临时播放地址不落库。
  • 接口返回 403/429 时不进行无限重试或并发预取。
